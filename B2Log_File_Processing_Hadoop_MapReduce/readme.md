AIM:
To design and implement a distributed application using Hadoop MapReduce to process a system log file and count the occurrences of different log types such as ERROR, INFO, and WARNING.

DESCRIPTION:
In this practical, Hadoop MapReduce framework is used to analyze a log file generated by a computer system. The log file contains different types of messages such as ERROR, INFO, and WARNING. The program reads the log file, identifies the type of each log entry, and counts how many times each type occurs.

The application uses two important components of MapReduce:

1. Mapper
2. Reducer

The Mapper extracts log types from the input file and generates key-value pairs. The Reducer receives similar keys together and calculates their total count.

WORKING OF PROGRAM:

1. Input Log File:
   The input file contains log messages such as:

ERROR Disk failure
INFO User login
ERROR Network issue
WARNING Memory low
INFO File uploaded
ERROR System crash

2. Mapper Phase:
   The Mapper reads the file line by line.
   It separates the first word from each line using split() function.

Example:
Input Line:
ERROR Disk failure

Mapper Output:
(ERROR,1)

Similarly:
(INFO,1)
(WARNING,1)

Each log type is treated as a key and value 1 is assigned to it.

3. Shuffle and Sort Phase:
   Hadoop automatically groups identical keys together.

Example:
(ERROR,1)
(ERROR,1)
(ERROR,1)

(INFO,1)
(INFO,1)

(WARNING,1)

4. Reducer Phase:
   Reducer receives grouped values for each key and performs addition.

Example:
ERROR → 1 + 1 + 1 = 3
INFO → 1 + 1 = 2
WARNING → 1

5. Final Output:
   The program generates the final count of each log type.

OUTPUT:
ERROR 3
INFO 2
WARNING 1

CODE EXPLANATION:

1. Import Statements:
   The required Hadoop and Java libraries are imported for configuration, file handling, Mapper, Reducer, and data types.

2. Mapper Class:
   The Mapper class processes input records.
   It extracts the first word from every line and sends it as output with value 1.

3. Reducer Class:
   The Reducer class receives grouped log types and sums their counts to produce final output.

4. Main Method:
   The main method configures the Hadoop job by setting:

* Mapper class
* Reducer class
* Input path
* Output path
* Output key and value types

Then the Hadoop job is executed.

COMMANDS USED:

1. Create Project Folder
   mkdir logprocessor

2. Move into Folder
   cd logprocessor

3. Create Java File
   gedit LogProcessor.java

4. Create Input Folder
   mkdir input

5. Create Input File
   gedit input/log.txt

6. Compile Java Program
   javac -classpath $(hadoop classpath) -d log_classes LogProcessor.java

7. Create JAR File
   jar -cvf logprocessor.jar -C log_classes/ .

8. Run Hadoop Program
   hadoop jar logprocessor.jar LogProcessor input output

9. Display Output
   cat output/part-r-00000

VIVA QUESTIONS AND ANSWERS:

Q1. What is Hadoop?
Hadoop is an open-source framework used for distributed storage and parallel processing of big data.

Q2. What is MapReduce?
MapReduce is a programming model used in Hadoop for processing large datasets using Mapper and Reducer.

Q3. What is the purpose of this practical?
To analyze a log file and count occurrences of different log types.

Q4. What is a log file?
A log file stores system-generated events, messages, and activities.

Q5. What does Mapper do?
Mapper reads input data and generates intermediate key-value pairs.

Q6. What does Reducer do?
Reducer combines values of same keys and generates final output.

Q7. What are key-value pairs in this program?
(ERROR,1)
(INFO,1)
(WARNING,1)

Q8. Why is Hadoop called distributed computing?
Because processing is distributed across multiple machines.

Q9. What is the role of split() function?
It separates words from each line of the log file.

Q10. Why do we create a JAR file?
Hadoop executes MapReduce applications through JAR files.

Q11. What error occurs if output folder already exists?
Hadoop shows:
“Output directory already exists”

Solution:
rm -r output

Q12. What is the final output of this program?
The total count of each log type.
